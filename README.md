# 💰 Simple Interest Calculator

## 📌 Project Overview
This project is a simple Python-based application that calculates **Simple Interest** based on user input values.

It is designed to demonstrate basic programming concepts such as:
- Functions
- User input handling
- Error handling

---

## 🧮 Formula Used
Simple Interest (SI) is calculated using:

SI = (P × R × T) / 100

Where:
- **P** = Principal amount  
- **R** = Rate of interest (%)  
- **T** = Time (in years)  

---

## 🚀 Features
- Accepts user input for principal, rate, and time  
- Calculates simple interest instantly  
- Handles invalid inputs gracefully  
- Clean and easy-to-understand code
